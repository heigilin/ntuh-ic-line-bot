# 庫賈氏病 CJD 院內系統勾稽紀錄怎麼查

院內 CJD 程式自動勾稽紀錄可由 portal 的手術或檢查排程畫面查看最新勾稽歷程。顯示「列管中」時，需採取相對應感染管制措施；顯示有勾稽紀錄且皆無列管時，仍須配合臨床病史、處置部位與醫療團隊進行風險評估；若畫面沒有勾稽紀錄，請查看交班單或改做手動查詢。程式勾稽範圍為排程前 6 日至後 2 日。詳細畫面與 API 歷程查看步驟請由 KM 開啟「庫賈氏病單筆勾稽、批次查詢、查看API歷程操作方法」：https://km.ntuh.gov.tw/km/readdocument.aspx?documentId=157420

# 庫賈氏病 CJD 疾管署手動勾稽怎麼查

臨時排程、排程畫面沒有勾稽紀錄，或臨床已知有 CJD 風險疑慮時，須進行手動勾稽。手動查詢需使用醫事人員卡及單卡讀卡機，雙卡型讀卡機不適用；院所代碼為 0401180014。連結疾管署查詢系統取得結果後，須執行儲存，將結果留存於本院資料庫，作為院內勾稽紀錄佐證。操作畫面請參閱 KM「庫賈氏病單筆勾稽、批次查詢、查看API歷程操作方法」。

# 庫賈氏病 CJD 病人要做鼻腔手術怎麼辦

先確認病人是否為 CJD／vCJD 確定、極可能、可能、診斷未定或風險個案，並評估處置是否涉及中或高感染力組織。先查看院內 CJD 勾稽歷程或排程列管狀態；臨時排程或已知有風險時不得只等待批次勾稽。若必須進行手術，應事前通知手術室、供應室、感染管制中心及相關團隊，並依院內現行正式規範安排處置及器械分流。

# 庫賈氏病 CJD 病人鼻腔內視鏡或手術器械要怎麼處理

先依病人風險與接觸組織感染力完成器械分類。接觸中、高感染力組織的器械須與低感染力器械分流；無法明確區分時，依高感染力器械處理。器械後續去活化、封存、報廢或再處理方式，依院內現行「庫賈氏病感染管制措施」及供應室正式流程辦理，並保留跨單位通知、器械流向與處理紀錄。
