# 全傳染病台大感管線上互動衛教與臨床決策支援平台（GitHub Pages 串接規格）

本規劃案建立「全傳染病台大感管線上互動平台」，串接 GitHub Pages（網址：`https://heigilin.github.io/ntuh_cdc/`），供民眾進行圖卡衛教、漂白水計算、症狀自我檢測，並提供臨床醫護人員一鍵轉發衛教卡、查詢 ICD-10 診斷碼、HIS 檢驗醫令碼與隔離醫囑 ANN 代碼。

## 🧼 三、互動式漂白水清消線上計算器 (Web Calculator)

前端網頁提供動態調配計算元件，民眾輸入水桶容量或漂白水蓋數自動算比例：
1. **輸入**：水桶公升數（例如 `5` 公升水）。
2. **輸出 A (一般環境/門把 1000 ppm)**：需加入 `5` 瓶蓋漂白水（約 100 mL），配製 1:50 稀釋液。
3. **輸出 B (嘔吐物/排泄物 5000 ppm)**：需加入 `25` 瓶蓋漂白水（約 500 mL），配製 1:10 稀釋液。
4. **警示燈標籤**：🔴 **酒精對諾羅/腸病毒無效**！請使用含氯漂白水或肥皂洗手。
