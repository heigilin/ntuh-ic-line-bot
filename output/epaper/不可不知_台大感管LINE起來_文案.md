# 不可不知｜台大感管 LINE 起來

臨床忙碌時，感管問題常常需要立即確認：VRE 要怎麼解隔？評鑑委員可能會問什麼？佐證資料該去哪裡找？「台大感管 LINE 起來」希望把常用的感染管制資訊，整理成更容易查詢的 LINE 服務，讓同仁能用日常語句快速提問，查找臨床照護、隔離解隔、評鑑查核、旅遊疫情與衛教提醒等重點。

本活動自 2026年9月21日起至12月31日止。官方 LINE 帳號 @ntuhic。加入官方 LINE 帳號，完成指定體驗與問卷即可取得抽獎資格；早鳥完成問卷者享 5倍抽獎機會，有機會抽中摩斯漢堡套餐電子券。完整活動辦法請點網站連結。

## Qbee 可以幫什麼忙？

- 快速查詢 VRE 解隔、採檢、隔離與清消等臨床照護重點。
- 切換評鑑查核情境，整理委員可能提問、執行紀錄與佐證方向。
- 完成有效問答後，依系統開放填寫問卷並取得抽獎資格。
